## Blockdata 0x5CAA5E28: 100% structural (was "header partially decoded")
- Closed form found: let c = number of 0x04 bytes in bytes[28..36] (8-byte flag
  context spanning both the +28 and +32 dwords). total_size = 36 + 12*4^(c-1)
  for c>=1, else 36. Level L = c-1. Adaptive 4-ary quadtree, 4^L 12-byte records.
- Validated: `tools/blockdata_validate.py` -> 3,098/3,098 exact, 0 mismatches.
  Context distribution c=0..7 -> 424,660,930,738,256,74,14,2.
- Corrected earlier wrong claim (popcount of flags@28 / "data grows quadratically").
  The +32 dword is what separates the four largest sizes sharing flags@28=0x04040404.
- Rust: rewrote `crates/spore-core/src/blockdata.rs` (header 36 bytes, data from 36,
  `level_from_context`, `exact`). 8 tests. Full spore-core suite: 56 pass.
- Record semantics (node child-mask vs leaf) still unknown; only structure consumed.

## gmdl 0x00E6BCE5: major structural progress (10.9% exact)
- CORRECTION: offset 4 is a BIG-ENDIAN ref_count, not flags. Header size =
  64 + ref_count*12. refs are 12-byte entries (type 0x2F4E681B + 8-byte key).
  ref_count dist: 0 (2699), 1..11 (1510). mesh_count: 1 (2423), 2 (1715), 3 (70).
- Header fields shift by ref_count*12: mesh_count@8+r*12, bbox@12+r*12,
  idx_count@48+r*12, buf_size@56+r*12.
- Vertex section after index buffer: u32 K (3 or 6), descriptor of 12*(K+1) bytes,
  then u32 vcount + u32 vsize. vcount/vsize at index_end + 12*(K+1)
  (K=3 -> +48 stride 24; K=6 -> +84 stride 36).
- Single-stream closed form: total = 244 + idx*2 + vcount*24 holds exactly for
  459 samples (ref_count=0, mesh_count=1, K=3, stride 24, 124-byte trailer).
- Remaining: mesh_count>1 (1785), K!=3 (1130), variable trailer (834).
- Tools: tools/gmdl_validate.py, gmdl_trailer.py, gmdl_deep.py.
