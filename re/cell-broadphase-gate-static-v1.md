# E7F290 bounded broadphase predicate

Static disassembly of the installed `SporeApp.exe` identified in `cell-actor-geometry-consumer-static-v1.md`, SHA-256 `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`; preferred-base virtual addresses. The registered `cell_broadphase_gate_v1` is a checked numeric slice, not a source-byte run or live contact. The unregistered draft preserves the earlier version of that slice.

`E7F290` iterates pair records in the collection's reverse order, resolves the first then second word via `B71CC0`, and skips the pair if either resolution returns null. It invokes `E6D7F0` for each valid actor, first then second, providing a center and scalar. With separately rounded binary32 SSE operations, `E7F327..E7F37A` computes, in this order: `dz=a.z-b.z`, `dy=a.y-b.y`, `dx=a.x-b.x`, `sum=a.scalar+b.scalar`, `z2=dz*dz`, `y2=dy*dy`, `x2=dx*dx`, `distance=(z2+y2)+x2`, `sum2=sum*sum`. `COMISS sum2,distance` then `JBE` skips the call for below, equal or unordered; only ordered strictly greater calls `E7F170` with the two resolved actor pointers and the additional argument copied through x87 `FLD/FSTP` at `E7F383..E7F38D`. The predicate itself uses SSE, not x87. If exceptions are unmasked, COMISS or earlier arithmetic can fault; masked NaN produces unordered flags and JBE skips. This is not proof of an event or contact outcome.

The model takes two explicit geometry outputs, admits only finite inputs and finite intermediate results under scoped MXCSR `1F80`, retains subnormals and signed zeros, and returns bit-pattern intermediates and the strict predicate. A safe error is not the original exceptional/partial-effect behavior; it deliberately does not emulate NaNs, infinities, unordered or original status flags. The source's negative scalar behavior is left numeric rather than inventing a radius constraint.
