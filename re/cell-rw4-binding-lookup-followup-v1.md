`76F820` returns zero on a null input. Otherwise it reads input +18, calls `11E2150` for a count, iterates indexed `11E26D0` results, and compares a result word with `7000C` at `76F8C4`. On a match, `76F904` selects a result pointer and returns it; on exhaustion it returns zero. This is consistent with looking up the first SkinsInK section, but the helper methods and returned pointer's complete native type still require source-provider confirmation.

At `7758C5` and `77593F`, the caller invokes `76F820` on the acquired resource and the result of `73D170`. The retained caller pseudocode then dereferences each non-null returned object's +0C and maps word IDs across those referenced objects. The RW4 schema identifies SkinsInK +0C as a skeleton reference; associating the native return with that schema is an inference, and neither resource is established as the candidate Cell model or clip.

Callsite assembly corrects the unresolved pseudocode argument at `775BAB..775BCD`: `[EBP+24]` is pushed before the lookup argument. `76F820` receives only the following push and its caller removes four bytes; that earlier pushed value stays on the stack for `773DE0`. After the lookup, the caller pushes its result, `*ESI`, and a local address, calls `773DE0`, then removes 16 bytes. Thus `[EBP+24]` is the fourth stack argument of `773DE0`, consistent with its stack-derived copy destination. Its upstream identity remains open.

`76F930..76F99B` examines a mapping and parent arrays: for each nonnegative mapped ordinal, it walks up first-argument parents while a parent is unmapped, then compares the mapped ancestor to the second-argument parent at the mapped ordinal; roots are compared to -1. Negative entries are skipped. Its AL result starts zero and becomes one only upon reaching a mapped entry, with failed parent comparisons returning zero. Full caller argument roles and admissible bounds require independent source review.
