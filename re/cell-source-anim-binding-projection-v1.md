# Controlled source-data animation binding projection

`crates/spore-bevy/src/cell_source_anim_binding_v1.rs` provides an offline boundary for explicitly supplied creation and ANIM payloads. It hashes the in-memory bytes against caller-supplied expected SHA-256 values, checks resource kinds, parses exact CreatureData framing and part ranges, and extracts a bounded ANIM channel/descriptor metadata projection. Builder channels must equal that projection. The candidate keeps its admitted asset identities private and exposes immutable accessors; actor triple, creation key, ANIM key, resource pointer, owner, cache and binding remain distinct identities. The package path/key, expected digest, provider winner and stable file acquisition are supplied assumptions; the module does not prove those claims or full ANIM/keyframe validity.

The admitted hit or supplied successful builder path yields only the selected `009A3140` reference-operation projection from `anim_instance_reference_handoff_v1`, contingent on independent caller admissions that old slots remain stable until each read and omitted work reached `009A3396`. The operations are descriptions, not actual retains/releases or a completed instance installation. Hit requires a nonzero supplied binding and does not model cache lifecycle or null fallback. A supplied failed builder returns pending; it does not assume a fully zeroed allocation, safe null behavior or a successful fallback. The caller-provided body blocks and bounds have no automatic actor/creation provenance, even if channel words match the selected ANIM.

The standalone headless example test target imports the module for engineering use; the Cell gameplay update does not. `tools/build.bat test -p spore-bevy --example cell_source_anim_binding_check_v1` passed five focused tests after two development compile failures were corrected. These exercise digest rejection, malformed metadata rejection, immutable identity access, ordered reference projection and explicit pending/admission states using synthetic objects. No installed source payload, native runtime, palette mapping, animation sampling or visible playback was established by this test.

## Opt-in installed payload check

An ignored test additionally requires explicit `RUSTSPORE_INSTALL` and `RUSTSPORE_ANIM_BUILDER_FIXTURE` paths. It checks the selected Content and PatchData package hashes before and after, admits the explicitly selected Jawhead creation payload SHA-256 `2181f3b217d4b610ab10d4475412eba7789eb37b5a3bff1f164773026be6d71e` and ANIM payload SHA-256 `837a340a2b4b08e5c69b075abfa01a9a9d1f18195c446cb2cfbe3a06aa90a802`, and compares parsed channel/descriptor words against independently supplied, hash-pinned retained builder fixture case 30. It checks a changed expected channel is rejected and that changing an independent copy of the ANIM bytes does not mutate the admitted metadata. The supplied actor triple is controlled fixture input; it is not a demonstrated actor or cache binding.

The first two attempts failed because the test supplied `0001FFFF` as the `NativePackageIndex` group for the ANIM. The inspected native-index key for explicit ordinal 4845 is `87CB0177:EE17C6AD:00000000`; the other group's compatibility-index spelling is not interchangeable. After pinning the observed native key, the ignored test passed 1/1; the default target passed six tests with that test ignored. Independent review agreed with this bounded check, and a subsequent targeted run explicitly confirmed `SourceCandidate::admit` rejects mutated ANIM bytes under the original expected digest. Its retained log `target/cell-source-anim-binding-installed-test-v1.log` has SHA-256 `c8dceb5be320fa4d03aac0e8488db307125ec53cda7048058aab26edc51b5dd0`. Before/after package hashes cannot detect transient replacement between the separate index and payload reads. The retained builder fixture shares the selected source clip; its independently supplied metadata is not independent clip provenance, runtime actor provenance or a native playback observation. The check covers metadata only. No proprietary payload was written by the test.
