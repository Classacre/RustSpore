# E6A450 early producer: controlled original-instruction comparison plan

This is a design for independent review, not a prepared executable or result. It targets the static prefix in [the producer model note](cell-feeding-producer-prefix-model-v1.md) of the pinned `SporeApp.exe` SHA-256 `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`. Inputs and callbacks are synthetic. It cannot demonstrate a live actor, event, contact or gameplay.

The entry is a cdecl-style 14-word stack interface: output, two geometry pointers, depth bits, actor A pointer, definition A code, feature A code, feature A index, actor B pointer, definition B code, two other words, feature B code and feature B index. The argument layout, local stack and cleanup must be checked against the pinned listing and the final linked host. The feature-9 and definition-A-7 exits branch to `E6ADD1`, which pops the initial ECX save and returns. Definition B 7 calls E59B40 then pops that save and returns directly. Definition B 6 saves EBX/EBP/ESI/EDI, submits once, and then continues at `E6A548`; its eventual normal epilogue at `E6ADCD` pops those four registers and reaches `E6ADD1`.

The source caller reads the current-player ID indirectly via absolute pointer at `016B4BE4` and root `+411C`. A proposed isolated x86 host must allocate the exact required address range only if it is free, initialize a distinct canary-protected root buffer of sufficient size and bind that pointer explicitly, then verify the pointer/root and all buffers after the call. It must fail before source execution if the mapping is unavailable or overlaps anything. An absolute-address mapping is not evidence of the live global or the live current player. Actor/geometry/output identities, null handling and lifetime remain caller admissions.

For feature-9, A-7 and B-7 paths, copy the complete pinned function range through `E6ADD2` to preserve its internal branch targets. Redirect both early B-7 E59B40 call sites to a reviewed non-mutating recording stub, trap every unsupported external call and reject fixture inputs that could enter unsupported paths before invocation. The stub records all nine raw argument words, validates ordering/capacity and does not dereference pointers; the host must compare each pointer to the exact trusted buffer before reading or normalizing it. A success in either no-call path requires an empty log and untouched output; B-7 requires exactly one call, preserved geometry and output and model-consistent pending candidate.

For the B-6 pending-continuation branch, a **separate modified-source fixture** may redirect the first instruction at `E6A548` to `E6ADCD`, preserving the four-register epilogue after the recording stub returns. That deliberate branch patch stops before E673A0, rather than pretending it ran or returned. The patch changes original continuation bytes and must be reported independently from unpatched source execution. It also makes the fixture unsuitable for conclusions about the producer after the suspension boundary. The exact branch replacement, instruction boundary and target displacement require independent source and linked-byte review; the B-7 and B-6 E59 call sites must each route to the controlled stub, while every other reachable external call must fail closed. INT3/UD2 traps assume normal unhandled exceptions and do not guard against a debugger attaching later.

Independent plan review confirmed the required source range ends at **exclusive `E6ADD3`**, including the `RET` at `E6ADD2`. At `E6A548`, the six-byte instruction can be replaced by `E9 80 08 00 00 90`: the relative jump targets `E6ADCD` and the final byte is padding. That exact modification must remain visibly distinct from the unmodified B-7 fixture. The proposed global mapping must reserve the 64-KiB aligned range beginning `016B0000`, validate the complete allocation and root pointer, and reject collisions before executing anything. Trapping external calls alone does not prevent an unsupported branch from performing an earlier global or pointer read. Validate every input gate before invocation and independently audit the entire reachable CFG, including memory accesses before any trap.

The reviewed x87 wrapper and isolated no-source smoke are a starting point, not proof for this thunk. Bind the exact DLL and PE/source bytes, establish CPU/OS support and self-debugger checks, allocate four disjoint aligned FXSAVE images, and verify the caller's saved x87 state is admitted. The B-7 and B-6 cases execute source `FLD`/`FSTP`; test finite signed zero, normal and subnormal depths under CW `027F` and MXCSR `1F80`, preserving source stack, nonvolatile registers, x87 TOP/abridged tag and relevant status. Do not infer restoration of AVX, omitted FXSAVE fields or fault safety from the standalone smoke. The source recording stub and wrapper thunk must use no intervening FP/SIMD instructions, with independently audited linked bytes.

Before any source execution, prepare separately hash-pinned fixture source, exact byte span and every patch, DLL and host, compiler/linker observations, native/model adapter, corpus and no-retry runner. Audit the full reachable CFG, including all exits, register/stack balance, exact source-to-stub relative destinations, trap targets, buffer sizes, canaries and output protocol. A finite directed corpus must cover both feature-9 priorities, B-7 with both A-7 values and both player comparisons, A-7 exit, B-6 with both player comparisons, and nonfinite-depth rejection before invocation. Distinguish process-local pointer words from candidate data; compare geometry via validated trusted buffers and do not compare ASLR-dependent addresses across processes. Preserve every failed attempt and check pins immediately before and after. Post-build hashes, before/after checks, canaries, child timeout and debugger checks do not supply hermetic provenance, guard pages, stable-file admission, sandboxing or asynchronous fault recovery.
