# Bounded Cell impact flag comparison

`spore_core::cell_contact_impact_flag_v1::impact_flag` models the comparison at pinned PE `E67543..E67550`, after its caller has already supplied and committed the distance and resolved globals +70. Native `COMISS xmm0,[ecx+70]` compares distance against threshold; `JBE` selects zero when CF=1 or ZF=1, including unordered, while its fallthrough writes one. The model executes `COMISS` and `SETA`, which selects that same fallthrough condition. Its sole supported policy is MXCSR `1F80`: exceptions masked, DAZ/FTZ off and nearest rounding; both quiet and signaling NaN are unordered and may set invalid status. Native unmasked exceptions can trap before the store and are outside this model. The model discards resulting status and restores the caller's complete MXCSR; it does not claim native status or partial-write parity.

The optional `cell_contact_impact_globals_inspection_v1` example requires an explicitly named stable package and caller admission that the loaded globals remain unchanged. It requires unique key `A426730B:2A3CE5B7:00000000`, exact 276-byte layout and decoded SHA-256 `e8c4b80348fd8f3a1821533c87110315ba584f66f081d46305ff61ab6cbf8c72` before reading +70. Distance is supplied as raw binary32 bits; no actor, earlier +6C/bounds gate, provider selection, record, event, audio or live contact is inferred. See [input provenance](cell-contact-input-provenance-static-v1.md). Unchanged/stable path is an admission rather than an atomic snapshot guarantee.

On the explicitly named installed PatchData package, distance bits `40A00000` return 0 and `40A00001` return 1 against threshold bits `40A00000`. The older `Spore_Game.package` globals extent is rejected. Focused core tests cover threshold neighbors, signed zero, subnormal, infinities, both NaN classes and hostile MXCSR restoration; the example test rejects wrong layout/hash.
