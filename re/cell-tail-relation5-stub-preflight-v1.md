# E6A2B0 relation-5 direct branch: controlled-stub preflight

This is a preparation for review, not a native comparison. `tools/cell_tail_relation5_prepare_v1.py` creates `target/cell-tail-relation5-review-v1` from the previously reviewed direct host and pinned source bytes. It changes only the original `E6A2C2` call displacement and appends `mov eax,1; ret` at offset `0x192`; it fixes relation to 5 in the host. The intended call therefore substitutes a known nonzero result for `E6A250`, with no modeled callback mutations. Other original external calls remain in the relocated buffer and must be unreachable. The original call instruction is modified, and the stub is not original executable behavior.

Static branch hypothesis for independent review: at `E6A2B0` relation 5 falls through; the code saves ESI and EDI, calls the stub at `E6A2C2`, restores the caller's one pushed argument, and `test al,al` / `jne E6A35F` chooses the direct priority-`0x16` path. A failing selector/depth comparison branches to `E6A332`, which pops both saved registers and returns at `E6A334`; an accepted write restores both and returns at `E6A3C8`. This hypothesis requires a complete branch, stack, ABI, buffer, finite-input and linked-binary audit; it is not evidence that the path is reachable in the game.

The currently prepared six-byte stub returns a constant but **does not independently record an ordered external-call trace**. It is insufficient for the requested comparison until a separately reviewed instrumented stub or equally strong controlled trace records exactly one E6A250 substitute call, checks the supplied actor argument and records that no other call occurred. Any counter or call log must reside in an explicitly allocated, bounded writable buffer separate from executable memory; its absolute address or relocation must be verified against the linked host and included in the run receipt. The controlled callback must have an explicit contract for register, stack, memory and floating-state effects. All non-target calls must be made safe fail-closed, rather than relying solely on an invalid relocated call being unreachable. Do not run the current host.

Before any execution, independently verify the patch against the original image, the complete reachable CFG, call-site targets and return addresses, instrumented stub, fixed relation argument, no unsupported branch targets, all canaries and data ranges, source and binary hashes, compiler and Rust-adapter provenance, finite test cases and unique retained output. The direct relation-5 output can then be compared against `RelationFiveOutcome::DirectPriority22`, using current post-callback snapshots and no aliasing. Comparison would only establish a controlled fixed-result boundary, not real `E6A250` behavior, side effects, relation production, event dispatch or gameplay. SDK/toolchain/runtime dependencies and stable-file concerns remain separate limitations.
