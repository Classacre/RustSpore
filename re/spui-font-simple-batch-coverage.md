Prepared 2026-10-27; Rust batch execution remains open. The accepted curved VM's
opcode set contains the accepted rectilinear VM's opcode set and adds SHP32/33;
this batch exercises the shared generic curved path without modifying either
accepted implementation. This inclusion is a handler inventory, not proof that
all reached state branches agree.

The frozen original-instruction census contains389 simple glyphs and1556 fresh
native observations at15ppem. This audit rechecked every hint/raster hash and
native alpha/parsed hash/check. The other189 glyphs remain183 composites and6
empty. The prepared all578 verifier calls the actual package parser/scaler/PREP
and generic hint/raster methods; it contains no glyph-specific coordinates or
pixels. Each glyph is transactional: a typed failure discards its partial output.

execution, with shape/raster checks applied after opcode filtering; they are not
a claim of exact Rust support. Original trace stream/relativePC beyond100 glyph
bytes is historically mislabeled. Opcode values and whole numeric source state
remain retained; dispatch labels are deliberately absent from this numeric gate.

Current root handoff is font-simple-batch-review-packet-v1.json and fixtures-v3.
There are176612 expected numeric rows over389 originals. A successful Rust glyph
must match full points/touches/CVT/storage/graphics/references/axis/advance plus
both raw raster modes' events and every alpha byte. Final origin is original
8C0F7D..0FA8: subtract first current phantom then AND FFFFFFC0; raw gray stays
unchanged. No normalization, recoloring or hardcoded bitmap is introduced.
The comparator rejects any completed group mismatch and reports actual typed
exclusions separately. Initial packetsv1/v2 preserve pin-formatting history;
currentv3 uses the formatted v2 pending verifier with distinct composite/empty
classification. No original source/reference or accepted module was mutated.

This covers fresh glyph computation only. Persistent CVT/storage sequence order,
actual face/size selection and cache miss order, atlas packing/upload and shader
bindings, layout and full UI text remain separate open pipeline gates. In
particular1556 source/native observations are not broad Rust font acceptance.
