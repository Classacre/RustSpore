# E6A450 producer prefix: bounded model and update-path gap

`spore_core::cell_feeding_producer_prefix_v1` models the bounded prefix `E6A450..E6A540` using caller-admitted snapshots. The original x86 bytes were decoded statically from the installed executable identified in [the ordered trace](cell-feeding-candidate-producer-v1.md). The prefix rejects either feature code 9 first. Otherwise definition B code 7 produces a pending E59B40 candidate with selector 19 if actor A is the current player, or 0 otherwise, and exits before the tail. Definition A code 7 exits next. If B is 6, it returns a **pending continuation submission**, selector 18 if A is the current player or 1 otherwise. This is the E59B40 call before E673A0; the model executes neither call and provides no resume API. Any continuation must admit its mutations, preserved registers, subsequent source reads, pointer/geometry lifetimes and x87 state as detailed below. Other paths return `UnsupportedContinuation` before all remaining operations. Finite depth, x87 exception/stack state, geometry, actor identities and pointer lifetime are caller admissions; this is not an observed gameplay event or original-instruction comparison.

For the B-code-6 path, the `E6A4F0..E6A540` instructions load the binary32 depth before the call, retain the two geometry pointers in EBP/EBX and actor B/A pointers in ESI/EDI, respectively, and pop the loaded x87 depth into the E59 argument at `E6A532`. The cdecl call's observed code uses no x87 instructions, and the preserved-register assumption requires the actual call to honor its ABI. After return, `E6A548..E6A596` uses the retained actor pointers to read their current `+90/+94/+98` values and IDs, reads the current global root and its `+5190` then `+74`, and passes the retained EBP pointer to E673A0. These are reads at their source instruction sites, not permission to substitute freshly resolved actor or geometry pointers. The output and memory reachable through retained pointers can have changed via aliasing or externally admitted effects; the relevant live bytes and pointer validity must be admitted at each read. The calculation also requires a valid x87 stack/environment after E59 and reproducing its source operation order. A future resume protocol must carry both retained register identities and fresh per-site memory observations, not blindly freeze all pre-call state or re-resolve everything.

Focused unit tests use `tools/build.bat test -p spore-core cell_feeding_producer_prefix_v1 --lib`. They check branch precedence, feature payload preservation, player-dependent selector, the separate pending-continuation boundary, unsupported continuation and finite-domain rejection. The tests are synthetic; they do not validate runtime reachability or exact x87 state.

The next consequential gap is the remaining ordered producer and its source update inputs, not merely the other relation-5 tail branches. The continuation can submit before `E673A0` and later invokes `E673A0`, `E59CD0` and other calls with mutable actor/global state. As established in [the side-effect trace](cell-feeding-e673a0-producer-side-effect-v1.md), `E673A0` writes through a source-owned container. The producer must suspend across each external call, obtain fresh snapshots and preserve ordered mutations and floating-point state; the current tail model expects those admitted effects and does not supply them. Feature geometry and pair-to-feature traversal must also be source-backed before a real stage update can produce valid inputs.

The Bevy Cell application currently retains experimental `CellWorld` and source assets as inspection art, as documented in [the update-path audit](cell-source-health-update-admission-v1.md). Its prototype input, float health and food events do not establish source actor handles, resource bindings, source feature contacts, current player, event lifetime or callback effects. Wiring this prefix or tail to prototype food would fabricate those relationships. The meaningful integration target is a separately admitted source actor/event state with typed resolvers, fresh snapshots and an ordered producer continuation; until those are established, the prefix is a bounded source model rather than active gameplay.
