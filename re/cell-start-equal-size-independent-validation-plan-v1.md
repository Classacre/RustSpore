# Equal-size start transition: independent validation plan

This is a plan and static byte inspection, not a performed comparison. Target base `SporeApp.exe` SHA-256 `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`; virtual addresses below use preferred image base `00400000`. The draft `cell_start_equal_size_v1.rs` is unwired. No original instructions, test harness, game, GPU or Cargo code were executed for this plan.

## Exact boundary

The bounded target begins after successful definition resolution with the `E751C0` call's argument 5 equal to -1 and argument 7 equal to +0, on the `E74AAA..E74AE2` size path. `E74AAA` loads float 1.0 from `014861D0`; `E74AB2` addresses the definition's +304/+308 pair and `E74AC2` calls `4DF9A0`. That routine `4DF9A0..4DF9DF` converts each binary32 endpoint to a binary64 stack argument, passes RNG address `01602760` and calls `4BA080`. It commits the returned value to binary32 at `4DF9D6`, then reloads it. `4BA080..4BA0C7` computes high-minus-low and stores binary64, calls `935D40`, multiplies, adds low, stores binary64, and applies its two floating comparisons/clamps. `935D40..935D75` updates the 32-bit state by multiplication with `278DDE6D`, performs signed FILD and the source floating operations using constants at `0143F52C` and `01471B2C`, compares against 1, and may take its fallback. Its zero-input branch executes RDTSC at `935D46`; exclude zero seed for this gate. Independently verify the exact constant bytes and source spans before executing any snippet.

`E74AC7..E74AE2` then evaluates `(1 / [Cell global +514C]) * sampled_f32 * argument6` with x87 operations and stores the binary32 result. `E74AE6` branches out of this snippet into further actor creation; a bounded harness must stop before that branch and must not run constructor allocation or provider logic. Initial SSE branch instructions and external definition resolution are not part of this proposed arithmetic subgate and require separate verification.

## Independent input and oracle design

1. Extract the explicit scope-zero PatchData globals and Cell keys using the canonical `NativePackageIndex`, not the old index group labels. Require the package SHA-256 and decoded SHA-256 values in [the source-bound plan](cell-start-reference-source-bound-test-plan-v1.md); retain package hash before and after extraction with a stable/no-concurrent-mutation precondition. Verify the raw globals +34 ID, the Cell resource key and both +304/+308 endpoint bits, recording them independently. A matching `CellDefinition::structure_id()` alone does not authenticate the Cell resource identity. Do not select a native overlay winner from this fixture.
2. Independently compute a reference with exact integer/rational arithmetic and explicit x87 precision and rounding at each arithmetic operation and each binary64/binary32 store. Existing `tools/native_x87_probe.py` rational helpers are a starting point; review their independence and coverage of binary64 storage rather than calling `native_x87` as the oracle. `cell_request_rng_v1` is the implementation under test, so calculate the state transition and signed fraction independently from the source formula. The equal-endpoint simplification and RNG state must both be tested; no output claim may depend on substituting a binary32 RNG fraction.
3. Use the real candidate endpoints plus clearly separate synthetic equal positive-normal endpoint bit patterns. Cross both PC53 and PC64 and all four x87 rounding modes with masked exceptions; choose finite positive-normal global +514C and argument-6 values, including divisors and outputs near binary32 rounding/normal boundaries. Include several nonzero seeds, wrap in the state multiplication, and the state producing a zero RNG numerator as an explicit *rejected* draft case. Include rejected unequal endpoints, nonfinite/zero/subnormal operands, zero seed, PC24, unmasked exceptions, f32 underflow/overflow results and non-candidate identity. Record comparison denominators and all exclusions. Do not infer that the native routine rejects these fixture-policy cases.
4. Compare exact sample f32 bits, final f32 bits and post-call RNG word. Use directed-rounding witness cases where operation ordering changes an answer; test a successful draw followed by another draw and error paths where the Rust caller's by-value RNG is unchanged. The latter is the draft's transactional API restriction; the original can advance RNG before later code fails or mutates other state.

A rational-oracle-versus-Rust pass demonstrates consistency of two models only. Even when `native_x87` executes host x87 instructions, that is not a run of Spore's original instruction bytes and does not establish original executable runtime state, actor creation or source player selection.

## Stronger optional original-byte gate

A separately reviewed 32-bit host could test the original byte spans for the nonzero-seed, equal-endpoint branch, without launching Spore. The review must establish PE hash and exact instruction-boundary bytes, relative-call relocation/targets, the fixed absolute operands, ABI and stack alignment before execution. `4DF9A0` directly pushes absolute RNG address `01602760`; `935D40` uses absolute constant addresses. The candidate subspan at `E74AAA` also expects ESI to point at a definition, the global pointer at `016B4BE4`, and a precise pre-existing stack frame with +80/+78/+7C relationships that change after pushing the definition pointer. It cannot be called as a normal standalone Rust/C function. Build an explicit wrapper that reproduces that frame and return boundary; verify all register saves, x87 stack depths and branches against disassembly. Provide original-byte code pages RX, constants read-only, a bounded writable RNG word and bounded synthetic global object containing +514C, separate guarded definition/input/output/stack pages, and a trap immediately after the last admitted store. Use a child process with timeout and capture exit, canary/guard status and exact outputs. Reject zero RNG before entry, so RDTSC is unreachable; validate branch destinations and writable accesses, preserve and restore the host's FP environment and specify CW/MXCSR. Do not patch a source call or helper silently: any explicit stub must be identified and the resulting test described as conditional.

Review existing guarded fixture machinery such as `tools/anim_body_root_native_probe.py` for ideas, not as proof that this different ABI is safe. Pin executable SHA, copied original code/constants, host binary, wrapper source and case manifest. Run the host only after independent safety and instruction-coverage review. Require identical outputs to both the Rust result and independent oracle on every admitted case, and report crashes, unsupported inputs, unknown original control state and source-byte versus stub boundaries separately. A passing isolated snippet would establish only those instructions under the supplied state—not runtime reachability, actual RNG initialization, overlay choice, actor creation or full Cell behavior.
