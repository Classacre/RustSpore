# E55FB0 supplied-snapshot movement diagnostic

`cell_movement_snapshot_diagnostic_v1` projects one bounded source movement-accumulator operation from caller-supplied raw bytes. It does not capture process memory, discover a player, run original code, or update gameplay. Actor identity, lifetime, producer, the supplied delta, environment ownership and the relationship between the snapshots are caller admissions. No live actor or gameplay parity follows from a successful result.

The executable version, static dispatch and unresolved source input route are documented in `cell-input-movement-update-gate-v1.md`, `cell-movement.md`, and `cell-movement-accumulator-position-static-v1.md`. In particular, the player route conditionally passes through E6F620 and E6EF30; flow and runtime providers, input ordering and actor/cache ownership remain unbound. E55FB0 adds a caller-supplied 3-vector scaled by actor +BC to actor +90..+98 and, on the +248/nonzero and signed +250 >= 2 branch, to the indexed environment vectors. The later position updates have separate gates and callbacks and are not performed here.

Run with `cargo run -p spore-bevy --example cell_movement_snapshot_diagnostic_v1 -- ACTOR.bin ENV_VECTORS.bin XXXXXXXX YYYYYYYY ZZZZZZZZ`. The final three arguments are exact binary32 hexadecimal bit words. ACTOR.bin is a little-endian snapshot beginning at actor offset zero; required words are +90/+94/+98, +BC, +248, +250, and, only when reached, signed indices at +254. ENV_VECTORS.bin is the explicitly supplied vector array beginning at index zero, 12 little-endian bytes per vector. Each input is capped at 1 MiB. Source pointer validity, coherent snapshots and correct array base must be established independently; file structure alone cannot establish them.

The program prints original and projected actor bits and only changed environment vectors. It makes no writes to the input files. The model rejects invalid indices, truncation and nonfinite inputs or results rather than reproducing unsafe source memory behavior, and executes under scoped MXCSR 1F80 with caller state restored. The model's disjoint input/output admission is represented by separate immutable snapshot inputs and owned output buffers; it is not proof that real native buffers were disjoint.
