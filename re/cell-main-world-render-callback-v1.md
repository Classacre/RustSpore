# Conditional Cell main-world render callback chain

Static source only. SporeApp.exe SHA-256 `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`. Exact PE-mapped instruction bytes, selected table words, and a separate Ghidra 12.1.4 `-noanalysis` project/script/log for `E54B50`, `7522B0` and `74F700` are retained under `target/ghidra-cell-render-chain-v1/`. Manually seeded bodies/decompiler signatures and indirect call coverage are limited; loader warnings and unresolved library links remain. This is not an REA Evidence record, original execution, or an observed frame.

`E54B50` obtains the object at global `016B4BE8` +161CC, calls its virtual +13C, then calls virtual +0C on the returned interface with its four supplied arguments. Under the earlier documented conditional standard model-world identity, constructor `753859..753866` installs main table `0140D740` and object+4 table `0140D730`. PE words `0140D87C` and `0140D73C` are respectively `69CD40` and `7522B0`; `69CD40` returns `ECX+4` for nonnull ECX. Thus, with valid unchanged standard world and interface vtables, that part of `E54B50` reaches `7522B0` on the model world's secondary interface. After that interface callback `E54B50` re-reads the global/root before obtaining and calling the main animation world +161D0 virtual +0C; that separate call is not identified here as this render path. The Cell setup/roles and alias conditions remain those documented in `cell-animation-owner-palette-draw-static-v1.md`.

Within `7522B0`, the code has additional object, graphics state, range and flag branches. On the branch at `7524A6..7524CB`, flag bit `1000h` and a nonempty pointer range at secondary-interface +2E8/+2EC admit a call to `74F700`; a separate bit `2000h` and unequal +2FC/+300 pointers admit the second call at `7524F5`. The second pair is read after the first call and may have changed; either pointer inequality is only a source branch condition and does not validate a range or its lifetime. Inside `74F700`, conditional iteration reaches `74FC22..74FC35`, loading +D8 from a selected entry and calling `73FD30`; that entry is not independently established as an actor. Earlier trace `cell-gmdl-palette-render-state-v1.md` establishes the latter's conditional indexed mesh traversal to `73EDF0` and `11F94C0`, as well as the source mesh/descriptor association under fresh unmodified loading. The actual vector contents, object, flags, visibility, shader, actor and draw identity must still be established; a raw interface route does not show that Jawhead was rendered.

The image contains `E54B50` at callback-table word `01485F30`, and the image contains a literal `01485F24` at `015A9424`; these are static pointer-table observations. A bounded direct E8-rel32 byte scan found no candidate calls to `E54B50`, but cannot find indirect calls or prove absence. The conditional registration route consuming `015A9424` is now traced in `cell-render-callback-registration-v1.md`; dispatcher invocation and timing relative to the `E806E0 -> E53960 -> A06600 -> A06310` path remain unproved. In particular this note does **not** establish that the render callback occurs after the palette update, on the same model object/thread, or before its vector can be freed. No new source-backed live-animation implementation is justified until those scheduler, identity and lifetime gates are closed. No GUI, source gameplay or GPU was run.
