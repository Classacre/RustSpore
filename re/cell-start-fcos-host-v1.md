# Bounded host x87 FCOS helper

`crates/spore-core/src/native_x87.rs` exposes `Context::cos_magnitude_at_most_four` for finite retained x87 values with absolute magnitude at most four. On x86/x86_64 it executes the host processor's `FCOS`; outside the bound it returns `CosArgumentOutsideBound`, and other architectures return `UnsupportedArchitecture`. A finite result remains in 80-bit `Extended` storage until the caller explicitly commits it, for example with the separately RC-controlled `store_f32`. It does not use a library cosine or claim a mathematically exact transcendental.

The helper follows the existing sine helper's environment pattern: it saves the x87 environment, installs the context's masked-exception control word, loads the retained argument, executes `FCOS`, captures the status word immediately, pops the result and restores the saved environment in the same assembly block. All eight x87 registers are declared clobbered. C2 is inspected before accepting the result; a set C2 returns `CosArgumentReductionIncomplete`. The finite bound excludes the architectural large-argument reduction limit, but the check remains explicit. The helper neither sets MXCSR nor exposes native sticky flags. `Context` selects PC and RC and constructs a masked control word; it does not establish the original game's control word or full exception state.

Independent static review of the helper reported no source-order or environment-pattern defect on its declared host domain. The coordinating agent reports six `native_x87` unit tests passed. The FCOS boundary test exercises 12 control combinations: PC24, PC53 and PC64, each with nearest, down, up and toward-zero rounding. It checks that both signed zeros produce exact +1, that ±4 are admitted with equal negative outputs, and that the immediately adjacent binary32 values outside ±4 are rejected. The control-restoration test also invokes FCOS. These are bounded host tests; they do not execute the original Cell instruction stream or establish source parity for its orientation path. Results may depend on processor implementation.
