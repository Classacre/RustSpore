# Controlled two-actor producer prefix fixture

The opt-in source-player inspection now creates two separately checked actors
in its short-lived owned pool, retaining separately associated borrowed feature
snapshots. It supplies an explicit synthetic second transform, synthetic
definition codes `[2,7]`, and designates the first fixture handle as player.
These values are controlled fixture admissions, not observed source actors,
provider results or a live contact. The existing installed source inspection
supplies the retained feature rows; the second actor intentionally reuses that
snapshot as an explicit synthetic choice.

The fixture validates both actor handles and the player against the same owned
pool, rejects foreign, stale and identical actor handles, validates the selected
non-class-1 row indices, projects both supplied features, and computes the
bounded pair geometry. A separated pair stops. A small-distance pair requires
six explicitly supplied opaque frame words in normal-then-point order; absent
words are rejected rather than initialized. For a nondegenerate pair, the
modeled point/normal/depth feed the existing `E6A450` prefix model together
with raw fixture handles, current-player fixture handle, feature classes,
original indices and explicitly supplied definition codes.

The fixture can apply a pending submission to an explicitly supplied, disjoint
owned selection using the existing E59B40 model, after revalidating the fixture
player and both candidate actor handles. It admits that player identity remains
stable through the model's later player read. A B definition 7 path returns
after those modeled writes; a B definition 6 path remains pending before
E673A0 even after arbitration. Class 9 and A definition 7 can exit before
submission. No native E59B40 call, E673A0, callback, event, source provider,
actor registration, or gameplay is implemented. The safety checks,
pool identity and fixture player are application-owned policies and do not
claim source performed them. The prefix's synthetic unit evidence is distinct
from the individually pinned earlier original-byte geometry comparisons; no
contiguous native producer invocation was compared. The independent E59B40
model had a separately pinned original-byte comparison of 314 synthetic cases;
that evidence does not validate this full fixture composition. See
[arbitration comparison](cell-arbitration-native-comparison-plan-v3.md).

The original handoff and remaining lifetime/callback admissions are recorded in
[cell feature producer and callback boundary](cell-feature-producer-callback-integration-v1.md).
