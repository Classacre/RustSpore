## Root votes and policy

[MEASURED] The initial finalizer root must be parentless and have nonzero-spin
bit8 at+154. Scanning initial runtime order stops at the first presence-root
bit1 at+150, before processing that block's foot bit. Otherwise every
nonzero-foot bit4 votes for its nearest nonzero-spin ancestor, starting with
its parent. Increasing the maximum clears the candidate list; reaching that
maximum appends the ancestor. Equal-height candidates therefore retain this
native list order.

[MEASURED] Nearest-origin global166CFE4 uses **presence-spin+150**, not the
nonzero mask. A selected presence-only spine can subsequently fail the
finalizer's nonzero-spin admission. Earlier pseudocode-derived descriptions
that treated this nearest predicate as nonzero spin are superseded by the
instruction checks at9C38B7/9C38F5/9C392E/9C3973 and9C39F2.

All products and sums in nearest-origin selection are SSE binary32. In each
four-way loop, lane1 computes `(x*x+z*z)+y*y`; lanes0/2/3 compute
`(x*x+y*y)+z*z`. Every tail item uses the former order. Strictly smaller than
the current best wins, starting at positive MAX. Finite squared distances may
overflow to infinity, which never beats that initial best. A retained literal
rounding witness is `[41B4E6AE,3FFA4A0C,41E44F42]`: identical vectors in lanes0
and1 can choose different roots solely because the addition orders differ.

If nearest-origin finds no candidate, the authored-root candidate remains
eligible. Without that candidate, a nonempty maximum-foot list chooses the
strictly highest Y, starting at negative MAX. Y exactly negative MAX never
wins. That source boundary leaves the selected word FFFFFFFF; the bounded
candidate API preserves it, and admitted-root API returns an explicit error.

Without root or foot candidates, selection starts at initial root0. When
global1551A84 is nonzero and there are more than two nonzero spines, the
source counts direct nonzero-spine children, takes the first terminal spine,
and walks all parent edges `spineCount>>1` times. Reaching FFFFFFFF retains
root0. The resulting choice must still pass nonzero-spin admission.
