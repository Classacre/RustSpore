# Civilization vehicle-selector projection

`civilization_vehicle_selector_v1` is a bounded projection of original `FF0FB0` and its `FF0720` helper. It accepts a caller-supplied stable 16-word selector array and 16 triples and returns a borrow of the selected triple. Four record words select four search keys; a first match picks its index, and a missing or unsupported key picks zero. The supplied arrays are not asserted to be a live game object or installed asset. Helper callbacks, object lifetimes, provider selection, and the effect on the prototype Civilization game are not modeled.

The executable image SHA-256 is `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`. The source image's first four selector words at `015B5DF8` are `99E92F05`, `4E3F7777`, `47C10953`, `72C49181`, but the unit test supplies its own array and does not claim a live image table. Existing PE-mapped instruction listings are in `target/ghidra-civ-vehicle-receiver-v1/instructions.txt` and `target/ghidra-civ-factory-key-array-v1/instructions.txt`; `FF0FB0` has two calls to `FF0720` and two inline scans, all bounded at 16. Actor independently reviewed the projection against those source instructions without a blocker. A native execution comparison remains pending; the unit tests alone do not establish native equivalence.

A direct host is feasible in principle if independently audited: the original `FF0FB0` span `FF0FB0..FF108A` needs two rel32 calls redirected to copied `FF0720`; its two absolute table operands and the helper's one operand must point to one guarded synthetic 16-word table. The input receiver, record, 16 triples, returned pointer extent, registers, FP controls, linked relocations and process isolation require explicit guards. No such host has been executed and no source-selected model or gameplay rule follows from this projection.

The independently reviewed original `FF0FB0`→`FF0720` host executed once with externally pinned runner/host/manifest and matched eight fixed cases in `target/civ-selector-original-result-v1/receipt.json` (SHA-256 `e7fa1ab7ac4232a0b65ced47c942b13c65641613fcf2a29bca79c661ffc62e13`; stdout `029f3158f8020df20e8f282cf5c13df310b05349b20b3b3d5cc92b1ca92be583`). Cases cover all four branches, unknown/missing keys, duplicate first match and final index; table/triples are guarded synthetic values. The receipt's generic review reminder predates the actor's independent linked-source/ABI review. This validates the bounded source selection with controlled input, not a live vehicle, its provider or a selected model.
