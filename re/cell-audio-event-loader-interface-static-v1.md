# Audio event factory and property interface: static conditional join

This follows [the array reader boundary](cell-audio-array-property-reader-boundary-v1.md) and [samples consumer](cell-audio-samples-consumer-static-v1.md). Evidence is x86 PE instructions and image tables from `D:\Games\SPORE Collection\SporeBin\SporeApp.exe`, SHA-256 `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`. It is not a live event, loader, resource-selection or audio observation.

## Factory and object interface

Constructor `A19B90`, at `A19BCE`, installs factory vtable `01453310`. Its +2C word is `A175F0`, which enumerates resource types `02B9F662` and `02C9EFF2`; +1C is `A17A90`, +24 is `A19DE0`. The `A17A90` path allocates an 84h-byte object, invokes `A17A00`, and dispatches through the factory receiver's +24. With the named table still installed, that dispatch reaches `A19DE0`. The object constructor installs primary vtable `01452F40` and secondary vtable `01452EF0` at object +14. The secondary table's +4C is `A17580`; its +20 is `A18670`.

`A17580` calls that interface's virtual +20 lookup, requires Variant type `0020` and flags intersecting `0030`, and returns Variant +8 as count and Variant +0 as pointer. `A18670` searches the property-entry collection at secondary +10/+14, corresponding to object +24/+28, with an additional parent lookup path. Thus the interface can expose a list entry as an array, provided lookup selects that entry and its lifetime and outputs are valid. This is a distinct interface from the ordinary PropertyList base vtable `014087C8`, whose +4C word is zero; matching property framing alone does not establish an interface identity.

The consumer receiver's image table `01453880` has +130 `A2C520`, +138 `A230D0`, and +18C `A2BE00`; code at `A324D1` installs that table. In `A230D0`, a `(item, 02B9F662, scope)` key is sent through receiver virtual +18C; after success and when an output pointer is requested, the helper calls through the returned object's vtable to retain it before the later null test used to form its +14 secondary interface. That retain call requires a valid non-null object; the later null branch does not make a null success result safe on this route. If no output pointer is requested, that retain path is skipped. `A2BE00` includes a cached-object path and a path through `8DD7C0` and an indirect +0C call. This establishes a conditional interface bridge, not that the provider actually returns the object from the factory above, selects a particular event, or returns a valid non-null interface at runtime. Calls remain virtual and object/table state matters.

## Dedicated reader and limits

At `A19DE0..A19E32`, if the stream-related virtual +1C yields null, or its returned object's virtual +0C does not yield `34728492`, the function obtains a stream through virtual +18 and calls `A19CC0` on the object. The equal-marker branch skips this call. `A19CC0` reads the list count, handles a high-bit conditional extra key/provider path, sizes entries at object +24 via `6A2630`, reads entry IDs and invokes `A19520` for each Variant. This is a dedicated reader, not a call to ordinary `693EC0`.

`A19520` reads Variant type and flags with `93A370` using mode zero; for array flags with `(flags & 0030) != 0` and `(flags & 0040) == 0`, it reads count and stride via `93A3F0`, allocates their product, and dispatches by type. Type `0020` takes default `A19A9E`: stream virtual +30 receives the element pointer and stride, then the pointer advances by stride. The reader tests the returned value for nonzero, **not equality to stride**, so a nonzero short read alone is not proof of a complete element. It also clears flag bit 0. `A17580` itself does not reorder the returned array bytes.

The dedicated `A19520` scalar and typed-array dispatch tables map numeric types `0009`, `000A` and `000D` through `571DD0` to `93A3F0` with mode zero. That helper requires the requested four-byte typed read to be complete before `BSWAP`, supporting big-endian numeric input for each reached four-byte value. The Rust inspection parser applies this to scalar values and arrays only when their recorded stride is exactly four. For other numeric strides it preserves the `count * stride` inspection-framed bytes raw; that framing is not established as the native typed-stream consumption rule for unusual strides. This typed numeric result is separate from type `0020` sample records.

The mode-zero helper `93A370` swaps each two-byte word after a full typed read; `93A3F0` is the corresponding four-byte helper. These typed-header operations must not be silently applied to default array elements: those go through +30 directly. If and only if the selected event follows this factory and non-marker reader, the getter resolves that loaded property, count and stride match the decoded payload, and the actual stream +30 supplies every requested byte unchanged, the in-memory element matches its input bytes. On x86 the consumer's first 32-bit load interprets those bytes little-endian. The concrete stream implementation, complete-read behavior, factory registration/provider route, inherited-property selection and live event selection remain unproven; no on-disk-to-playback conclusion follows.

## Reproduction

Verify the executable SHA-256 first. With Python `pefile` and `capstone`, decode in x86-32 mode using `pe.get_data(start - pe.OPTIONAL_HEADER.ImageBase, end - start)` and instruction address `start`: ranges `A19B90..A19C26`, `A17A00..A17C30`, `A17580..A17630`, `A18670..A18780`, `A19DE0..A19E60`, `A19CC0..A19DDF`, `A19520..A19585`, `A19812..A198A4`, `A19A9E..A19AD5`, `A230D0..A23190`, `A2BE00..A2BF90`, `93A370..93A470` and the consumer ranges in the linked note. Read little-endian 32-bit image words at each cited vtable plus the indicated offsets. These ranges include branch-specific code; use actual instruction boundaries and follow branches instead of assuming a linear decode proves all paths. No game, GUI or Cargo was run.

Independent PE review checked these bounded paths and corrected the retain-before-null-test condition. It did not establish provider selection or a complete stream read.
