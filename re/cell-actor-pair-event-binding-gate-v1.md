## Distinct state and identities

supplied feature rows, transforms and definition codes. Its second actor and
current-player assignment are synthetic, its +90 snapshots are supplied, and
it stops before the native container/provider. The separate sweep fixture
owns a different checked pool and definition snapshot. Neither fixture's raw

## Next bounded source-backed implementation

Implement a **controlled E7F170 pair coordinator** inside an owned fixture,
not the prototype update, with explicit suspend/resume boundaries:

1. Receive two already checked same-pool actor handles and keep their original
   identities/pointer-like fixture tokens. Reject stale, foreign or equal IDs as
   a safe fixture boundary. Source `E7F17D..182` itself exits on equal first
   words before calling a resolver.
2. Model the two holder/definition-resolve operations in source order as
   pending external operations. Admit their distinct reference bindings,
   returned object identities, lifetime and fresh +B4 values; source resolves
   A then B, then tests A +B4 and B +B4 for zero. Release/cleanup operations are
   distinct pending effects, including early-zero paths. Do not read +B4 from
   a raw ID or assume a failed/zero native pointer is safe.
3. For surviving gates, create one shared selection snapshot. `E7F1EB..1FF`
   zeroes the first six dwords of the 12-word output; the remaining point and
   normal words are not initialized there. Preserve those six remaining words
   as opaque caller-admitted bytes until a modeled write replaces them; do not
   silently claim source zeroed them. Call the first selector with actor and
   definition order A/B, then the second B/A, passing the same output. The
   original actor and resolved definition pointers are retained across the
   calls; admit their validity and fresh memory values after each callback,
   rather than substituting newly resolved objects. All unmodeled feature or
   E6A450/E6A2B0 paths must stop pending.
4. Only after both passes and their effects are admitted, source tests the
   *current* output selector: zero and 0x16 skip E7E820; other values lead to
   a pending E7E820 call with the shared output and supplied float. Do not
   manufacture a selector-9/10 event from an intermediate E59B40 win. Holder
   cleanup is still pending even on the dispatch path.

The implementation is testable with two owned actors and explicitly scripted
