No native code, game or audio device ran. Object identity, vtables, cache state, array bytes, callback side effects, allocation, resource provider and lifetime are conditional; this is not a demonstrated collision cue or playback.

The image table `01453880` has `+160 = A28710` and `+194 = A29300`. If that receiver is the same table `01453880` and returns normally, `A28710` looks in a map at receiver `+118B90` using a caller-supplied key (`A28733..A28771`). A hit returns the cached object and does not inspect the newly supplied rows in this slice. A miss allocates an object and, after `A145B0`, walks the supplied signed count in order; for each positive-count entry it reads **only the first dword** and passes it to `A14580`, advancing the entry pointer by 12 bytes (`A2880C..A28831`). `A14580` appends that dword to a 4-byte vector, invoking a separate growth helper if needed. The exact marker/factory/getter and complete-read admissions in the loader note still apply before identifying any package bytes with these in-memory values. The remaining two dwords are not read by this specific population loop.

On the newly built path `A28835..A28837` calls `A14530` once, then stores the object in the map. `A14530` invokes `A144E0` over vector `[+08,+0C)` with callback `A14480`. For each position `i` starting at 1, `A144E0` calls the callback with divisor `i+1` and swaps entry `i` with entry at the returned index. `A14480` invokes import `MSVCR90.dll!rand`, executes signed `CDQ; IDIV divisor`, and returns the remainder; safe modeling therefore needs an admitted nonnegative CRT result, valid nonzero divisor, stable vector and exact call sequence. This is a forward shuffle of the supplied dwords, not a fixed first-entry selection. On a cache hit this newly built/shuffle branch is bypassed.

`A14530` then sets cursor `+9C` to vector start. If the vector contains more than one word and its first word equals stored previous word `+98`, it invokes `A144A0` once. `A144A0` returns zero for an empty vector; otherwise, if cursor is null or equals end it resets it to begin, reads one word, advances by four and stores that word in `+98`. The skip changes cursor and previous word; it is not a general guarantee that consecutive selections differ. Allocation path `A28790..A287BC` initializes `+98` to zero and cursor to vector start, but an existing cached object can carry different state. The caller `A204AB..A204C9`, conditional on its own `+2D8` pointer and `A14490` reporting a nonzero vector length, calls `A144A0` and stores its returned word at that caller object's `+40`. This closes a **conditional loaded-array-to-selected-word** join under the receiver, input and state admissions. It does not establish how that word is subsequently bound to a sound voice.

Separately, the `+194` call in `A2D370..A2D3B1` can dispatch to `A29300` if the same named table is installed. That routine tests manager maps, counters and cache state, and on another path obtains an object through +188 and virtual +34, then calls through a further object's virtual +10 (`A2944F..A294B6`). Those steps show more conditional resource/object handling; their receiver identity, exact contract, downstream stream, start command and audio output remain unresolved. In particular, `A29300` is not by itself proof of sound playback, and it is not established that the `A203` selection and `A2D3` prefetch-like path belong to one live event.

A bounded next implementation can model only the shuffle/cursor object with explicitly supplied nonnegative `rand` results, initial vector, cursor and previous word, including cache-hit/no-rebuild, duplicate/zero words, empty vector, first-word skip, cycle wrap and exact draw count. To join a package, require explicit event and SNR packages, unique exact keys, an admitted factory/stream with full reads and an admitted cache miss or hit. A selected dword can conditionally form the SNR key already established at the other consumer, but no automatic Cell collision/feeding cue or voice playback is justified until the two consumers, selected-word use, native event routing and actual output path are joined.
