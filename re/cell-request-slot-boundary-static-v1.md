# Cell request to animation-slot boundary: retained static trace

This is a read-only analysis of retained Ghidra dossiers for `SporeApp.exe`, SHA-256 `17cf32b3e3adbcc7ed9c4e593c83b5d3deb3c675059b7ad9cbfd19192df5f87a`. No game, Cargo or native host was run. It narrows a feasible fixture boundary, not live actor selection or playback.

`A0C120` (dossier `target/rea/20261027-source-runtime-v4/53-analyze_function.json`) looks up the supplied request key and returns zero for a missing record or empty variant vector. For multiple variants it uses an explicitly supplied in-range index, otherwise calls `935F40` and scans ordered thresholds; it writes the chosen index back when the pointer is non-null. It copies each selected 28-byte entry into a three-word sequence ordered +8, +4, +0. At `A0C376` it passes that sequence and count, object +184, and the word obtained through `[[object+190]+1C]+14` to `A01A20`. That nested word's semantic identity and lifetime remain unproved.

`A01A20` (dossier 52) rejects a zero second argument or a slot index at least 16. It initializes the selected 0xF0-byte slot and copies at most eight three-word records, then constructs a handle `(*manager << 8) + 1 + (index & 0xff)`. It calls `9FFA20` and, if that returns zero, calls `A00B30`; the function returns the constructed handle without checking `A00B30`'s return. Therefore a nonzero request result alone is not proof of successful fallback allocation or binding. Dossier 48 shows `A00B30` itself finds another slot and may return zero when no slot is available, then on its admitted path calls `9A4430` and `9A3140`. The cache and instance handoff details and additional call-domain limits are in `anim-binding-cache-handoff-static-v1.md`.

A useful next bounded test is a source-instruction-reviewed request-to-slot fixture using explicit record, variant-index pointer, manager generation, slot occupancy, owner word and cache outcomes. Cover absent key, empty variant, valid and invalid variant index, threshold boundary, zero owner word, 16-slot exhaustion, eight-record truncation, `9FFA20` success, and `A00B30` failure; assert return value separately from actual instance/binding state. Review the raw assembly and helper side effects before implementing or claiming native equivalence. The selected Cell table request, mounted AnimList precedence, object +190 provenance, actual loaded ANIM, cache ownership and palette-to-draw path remain independent gates. A fixture cannot convert a caller-selected actor or clip into observed gameplay.
